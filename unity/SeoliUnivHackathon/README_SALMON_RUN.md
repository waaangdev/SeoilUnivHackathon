# Salmon Run

탑뷰 방식으로 아래에서 위를 향해 거슬러 올라가는 2D 연어 러너 프로토타입입니다.

## 실행

1. Unity 6000.5.10f1에서 프로젝트를 엽니다.
2. `Assets/Scenes/SampleScene.unity`를 엽니다.
3. Play 버튼을 누릅니다. 별도의 씬 설정이나 프리팹 배치는 필요하지 않습니다.

## 조작

- 이동: `WASD` 또는 방향키
- 점프: `Space`
- 점프 중에는 해초, 나뭇가지, 통나무, 돌, 부유물, 어두운 물웅덩이와 강을 가로막는 쓰러진 나무를 넘을 수 있습니다.

## 게임 흐름

- Stage 1: 바다 / 아침 — 쉬운 장애물과 주기적인 파도
- Stage 2: 강 하류·상류 / 노을 — 강한 급류와 길을 막는 장애물
- Stage 3: 끝없는 밤의 강 — 화면 전체 안개, 추적 피라냐, 전기뱀장어, 곰 발톱, 회전 그물
- Stage 3 완료 후 게임은 끝나지 않습니다. 체력이 0이 될 때까지 밤의 강 난이도가 무한히 상승합니다.
- 난이도 상승 시 이동 속도, 함정 빈도, 피해량, 장애물 속도와 복합 장애물 배치 확률이 함께 증가합니다.
- 스테이지가 바뀔 때 플레이는 끊기지 않으며, 6.5초 동안 물빛·강둑·강폭이 자연스럽게 변하면서 다음 지형으로 이어집니다.
- 1·2스테이지의 기본 진행 속도와 함정 빈도가 높아졌습니다. 파도는 미리 경고되며 점프로 밀려나는 거리를 줄일 수 있습니다.
- 해초, 나뭇잎, 해파리, 바위, 통나무, 급류와 물웅덩이는 각기 흔들림·회전·박동·횡이동 애니메이션을 가집니다.

초록 회복 구슬을 획득하면 체력을 최대 25 회복하고 100점을 얻습니다. 장애물을 아슬아슬하게 피하면 추가 점수를 얻으며, 이동 관성·점프 물보라·피격 화면 흔들림·회복 플래시가 조작 피드백을 강화합니다.

로비의 설정 버튼에서 전체 음량을 조절할 수 있으며, 게임 종료 화면에서 즉시 다시 시작하거나 로비로 돌아갈 수 있습니다.

## 코드 위치

- `Assets/Scripts/SalmonRun/SalmonGame.cs`: 전체 게임 루프, UI, 스테이지, 점수와 체력
- `Assets/Scripts/SalmonRun/SalmonHazard.cs`: 장애물 동작
- `Assets/Scripts/SalmonRun/SalmonVisuals.cs`: 런타임 2D 그래픽 생성
- `Assets/Scripts/SalmonRun/SalmonGameBootstrap.cs`: 현재 씬에서 게임 자동 시작
